Featured Infrastructure

Serverless PWA

Recipe Keeper & AI Extractor

I migrated a standalone frontend application into a fully serverless AWS environment. The infrastructure is provisioned entirely via Terraform (IaC) for reproducible, terminal-driven deployments.

  • API Gateway & Lambda (Node.js): Bypassed frontend CORS restrictions for reliable web scraping.
  • AI Integration: Securely integrated Google Gemini for photo-to-text extraction, locking API keys inside AWS Secrets Manager.
  • AWS Cognito: Implemented JWT authentication to isolate guest users (like recruiters) from synchronized family cookbooks.
  • DynamoDB & S3: Partitioned user data at scale, paired with private buckets for image storage.
  • Global Delivery: Distributed the PWA via Amazon CloudFront with offline Service Worker support.
